To run the project, simply download Android Studio at https://developer.android.com/studio

Then, download the repository and open the project. Alternatively, you can clone the repository to open it that way.

Finally, navigate to the MainActivity.kt file and click the green triangle next to the MainActivity function.

If you have the Android emulator set up properly, this should launch the app in the emulator.

To use this app, you can click the light and dark buttons on the top right to override the app's theme (regardless of current system theme) to light theme or dark theme, respectively. Long pressing releases the override.
To add notes, click the + button in the bottom right corner; a dialog should appear prompting you to enter a title and contents for the note.
To edit existing notes, double tap (click) on an existing note, make your changes, then confirm with the 'update' button. (This is to alleviate accidental edits when scrolling through notes.)
Deleting a note can be done by editing a note and selecting 'delete' instead of 'update'.

To cancel adding or editing a note, either tap outside the dialog or use the 'dismiss' button.
